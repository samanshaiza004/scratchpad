## Million-line semantic-plan worker

The opt-in bridge diagnostic ran in three independent processes against the
current pinned Caliber and Alicorn. Each process built plans for a generated
18,981,000-byte prose fixture containing one million newline-terminated rows,
1,000 paragraphs, and 1,000,001 buffer lines including the trailing empty
line. Each run collected 20 successful worker requests and one cancellation.

| 3 | 27.411 / 28.973 ms | 27.243 / 28.758 ms | 0.073 / 0.080 ms | 55.71→87.54 MB | 56.86→88.59 MB |

For process 3, a macOS `getrusage(RUSAGE_CHILDREN)` wrapper measured **121.29
MB peak RSS** for the diagnostic test process. This is process RSS for the
isolated Go bridge diagnostic, not the Scratchpad GUI's working-set/high-water
memory during application use. Go heap values are shown separately because
they are not process RSS.

The repeated worker measurements are consistent: construction completes in
roughly 27–31 ms at p50/p95, and the observed cancellation exits within 0.08–
0.13 ms. They establish worker behavior for this synthetic fixture; they do not
measure native input-to-visible latency, first accepted typing/scrolling, AX
serialization, or full application memory.

## Physical acceptance and limits

On 2026-11-11, the maintainer reported that all Scratchpad checks on the Mac
were completed and green, and authorized release closeout. This is
maintainer-reported physical acceptance; no per-scenario transcript, IME
engine/version record, or timing capture accompanied the confirmation. The
Windows physical acceptance and its limits are recorded separately in the
[Windows report](issue-17-windows-2026-11-10.md).

Across the two platforms, physical behavior is accepted for this release
candidate. Numeric native UI-to-visible latency, time-to-first-input under a
pending plan, and full GUI-process memory high-water were not instrumented and
are not claimed. The worker timings above characterize background plan work;
they do not substitute for those metrics. Issue #17 records this distinction
as an accepted measurement limitation, not as a claim that those metrics were
measured.

## Closeout

The full Go, bridge, Alicorn type-check, and 243-test Odin frontend suite passed
on the locked source/dependency candidate. The macOS arm64 package passed native
dependency and signature audits plus relocated/extracted launch smoke. The
maintainer confirmed the complete physical Mac pass; Windows evidence is in
the companion report. The package artifact is a local candidate, not a
published release asset. v0.2.0 is ready for publication after the issue is
closed.
